# BEYOND

**More than social.**

BEYOND is a native iOS social experience built with Swift and SwiftUI.

## Product direction

- Default language: Turkish
- Additional language: English
- Platform: iPhone
- UI: Native Apple SwiftUI components and SF Symbols
- Minimum deployment target: iOS 17

## Engineering principles

- Prefer native Apple frameworks and system components.
- Avoid third-party UI frameworks and copied interface kits.
- Respect Safe Areas, Dynamic Type, accessibility, and system appearance.
- Keep features modular and reviewable through focused pull requests.
- Validate every change with an Xcode build before considering it complete.

## Build

Open `BEYOND.xcodeproj` in Xcode and select the BEYOND scheme.
